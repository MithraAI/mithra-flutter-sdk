# Security Policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public GitHub
issues, discussions or pull requests.

Report them privately through GitHub's private vulnerability reporting:

1. Go to
   <https://github.com/MithraAI/mithra-flutter-sdk/security/advisories/new>
   (or open the repository's **Security** tab and choose
   **Report a vulnerability**).
2. Fill in the form. The report is visible only to you and the Mithra
   maintainers.

Please include as much of the following as you can:

- the affected package version (`mithra_flutter_sdk` in your `pubspec.lock`)
  and platform (iOS, Android or both);
- a description of the issue and its impact;
- steps to reproduce, or a proof of concept;
- any known mitigation or workaround.

We will acknowledge your report, keep you updated in the private advisory
while we investigate, and credit you in the published advisory if you wish.
Please give us a reasonable time to release a fix before disclosing the issue
publicly.

## Supported versions

Security fixes are released in a new version of the package. Only the latest
release receives them, so please make sure you can reproduce the issue on it
and upgrade to it once a fix is published.
